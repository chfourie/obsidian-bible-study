## What to build

The pure highlight stroke engine — the single new seam owning all mutation semantics, fully unit-verified, no UI.

- Stroke application: painting a slot over existing cues claims the overlap (last stroke wins, older spans split into remainders); same-slot strokes merge with touching/overlapping spans; eraser strokes remove with the same splitting rules. Output is always canonical: sorted by (verse, start), non-overlapping, no zero-length spans, split at reference gaps.
- Selection mapping: (verse texts + selection endpoints) → cue spans, snapping outward to word boundaries where the text is whitespace-scripted (CJK/Thai store exactly as selected), clamping to passage verse text.
- Minimal-diff token rewrite: original token text + new cue set → new token text. User's reference spelling, token order, and spacing preserved; explicit translation token inserted if absent (Pinned Translation); cue tail replaced in canonical form, always last. Erasing the last cue leaves the pinned translation token.

## Acceptance criteria

- [x] Paint/erase/merge/split/last-stroke-wins covered by unit tests, interval-math style
- [x] Gap-splitting and clamping against verse texts covered
- [x] Word-boundary snap applies only to whitespace scripts
- [x] Rewrite preserves original spelling/spacing byte-for-byte outside the cue tail and pin insertion
- [x] Pin inserted on first highlight; retained on full erasure
