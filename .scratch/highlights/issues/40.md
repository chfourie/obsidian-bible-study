# Highlights 2/4: configurable palette settings

## Parent

#38

## What to build

The global Highlights palette becomes configurable. A new "Highlights" settings section shows the five Highlight Slots, each with a light-mode and a dark-mode color picker, plus reset-to-defaults. Changing a slot's color immediately re-tints every highlight in the vault that uses that slot (cues store only the slot index).

- Settings persist the 5×2 palette; emission updates the `--ss-hl-1`…`--ss-hl-5` CSS variables per theme scope.
- Slots are positional colors only — no names, labels, or semantics.

## Acceptance criteria

- [ ] Five slot rows, each with light + dark pickers, under a Highlights section
- [ ] Reset restores shipped defaults
- [ ] Recoloring a slot re-tints existing rendered highlights without re-editing any note
- [ ] Settings seam tests cover persistence and CSS variable emission
