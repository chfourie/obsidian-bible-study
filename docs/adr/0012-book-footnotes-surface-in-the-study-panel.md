# Book footnotes surface in the Study Panel, never on the page

Charles 1912 prints a critical note on almost every verse; *Humility* has three in the whole book. A marker or under-verse apparatus would wreck the quiet book page. A note’s chip / inline / block quoting that atom would inherit the same wreckage.

**Decision:** no marker in the atom. Selecting the atom lists its Footnotes in the Study Panel. Chip, inline, and block suppress both marker and body. Same rule for dense and sparse Books. Default is that placement — no On/Hover/Off for footnotes.

**Rejected:** under-verse apparatus; popover on a superscript; marker-only in notes; a hide toggle.
